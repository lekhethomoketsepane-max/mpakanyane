Mpakanyane Tours — Lesotho Tourism Website

Mpakanyane Tours (branded under the Klein logo) is a responsive, multi-page tourism web application showcasing Lesotho's destinations, cultural heritage, and travel experiences. Developed for Web Design (BIWD2110) at Limkokwing University of Creative Technology.

Project Overview

Mpakanyane Tours highlights tourism across Lesotho through five interconnected pages designed to adapt smoothly across mobile, tablet, and desktop viewports:

index.html — Home page featuring the Klein brand mark, Mpakanyane Tours overview, featured Lesotho destinations, and site navigation.

about.html — Information about Mpakanyane Tours, its mission, and guided travel offerings.

basotho.html — Dedicated showcase of Basotho culture, heritage, traditions, and local experiences.

galari.html — Interactive photo gallery highlighting Lesotho landscapes, landmarks, and activities.

contact.html — Contact and tour inquiry/booking page with interactive form validation.

Technologies & Features Implemented

HTML5 & Accessibility

Semantic HTML5 document structure using <header>, <nav>, <main>, <section>, <article>, <aside>, and <footer>.

Descriptive alt attributes across all imagery (including logo and gallery assets), clear heading hierarchy, and accessible navigation.

CSS3 & Bootstrap 5

External CSS stylesheets (css/) implementing custom typography, color palette, spacing, Flexbox/Grid layouts, hover effects, transitions, and custom component overrides.

Bootstrap 5 responsive grid system (container, row, col-*) across breakpoints (sm, md, lg, xl, xxl).
